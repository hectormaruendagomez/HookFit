HookFit

AI SaaS para creadores de contenido fitness: ayuda a mejorar y optimizar el contenido en formato corto (reels/shorts) para redes sociales.

🔗 Demo: hookfit.es

Stack técnico
Frontend: React, Vite, Tailwind CSS
Backend: Node.js
Base de datos: Supabase (PostgreSQL)
Procesamiento de vídeo: Cloudinary
Despliegue: Docker + Railway (backend), Vercel (frontend)
Funcionalidades
Sistema de pagos y planes (columna is_pro, verificación de suscripción)
Procesamiento e integración de vídeo vía Cloudinary
Interfaz con soporte multiidioma
Estructura del proyecto
├── src/          # Frontend (React)
├── server/       # Backend (Node.js)
├── public/       # Assets estáticos
├── imagenes/     # Recursos visuales
├── Dockerfile    # Contenedor para despliegue en Railway
└── railway.toml  # Configuración de despliegue
Mi rol

Desarrollo full-stack en solitario: diseño de producto, frontend (React/Tailwind), backend (Node.js), integración de pagos y despliegue (Docker/Railway/Vercel).
